Workshop modifications: Node/tsx instead of Bun; npm workspace scripts; SDK v2 automatic protocol negotiation without deprecated SSE fallback; loopback binding and host/origin checks; workshop links; explicit message capability; iframe title; `srcdoc` loading for the embedded React document; cache headers for local development.
